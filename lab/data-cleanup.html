Inventory CSV Cleanup Demo

A small browser tool for standardizing fictional inventory records, filtering review items, excluding rows from a clean export, and handing off both outputs.

ROLE

FORMAT

TOOLS

Portfolio demo with fictional data

Why I built it

Inventory lists are easier to maintain when IDs, quantities, and locations follow the same rules. I built this exercise to show a practical data handoff: standardize the format, filter the rows that need attention, make exclusions reversible, and export both a clean list and a review trail.

Operating procedure

  1. Load the records

    Use the fictional sample or paste a CSV with the four required headers.

  2. Standardize and check

    Normalize SKU case and spacing, then check required fields, numeric quantities, and repeated SKUs.

  3. Filter and decide

    Filter ready and review rows. Exclude a row from the clean export when appropriate, or restore it before handoff. The source remains untouched.

  4. Export both outputs

    Download ready rows for use and a reviewed CSV with every source row and its status for follow-up.

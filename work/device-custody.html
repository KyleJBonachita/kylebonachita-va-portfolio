BUILT PROJECT / WEB + INVENTORY

Device Custody Tracker

A responsive Google Apps Script web app for tracking individual devices through checkout, return, condition review, and shift audits.

ROLE
Workflow, data model, interface and testing
FORMAT
Responsive Apps Script web app
TOOLS
Apps Script, Sheets, HTML, CSS, JavaScript
STATUS
Current version in editor test deployment

The problem

Paper checkout and turnover logs make it harder to see each device’s current condition and custodian. A shift team needs a clear record of what went out, what came back, and which exceptions need attention.

What I built

  • Individual inventory records for each device, including status, classification, and condition.
  • A checkout and return flow that temporarily groups two phones under one borrower, then returns each to individual inventory.
  • QR verification, issue records, and end-of-shift audits in an append-only event history.
  • Administrator and viewer roles with server-side checks on changes.
  • Team-ready status summaries that can be copied into Microsoft Teams.

Why it works this way

Keep each device distinct. A temporary pair is useful during checkout, but each physical device remains its own inventory record.

Record the handoff. Checkout, return, transfer, and issue events form a trail that a shift team can review.

Design for the floor. The interface adapts to phones and desktops so a handoff can be checked where it happens.

Current status: The current version is in an editor test deployment. This case study shows its design and build; it does not claim the latest version is publicly deployed or report production metrics.

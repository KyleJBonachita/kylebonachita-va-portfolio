BUILT WORKFLOW / POWER AUTOMATE

Morning Tech Team reminder

A scheduled Teams Adaptive Card reminder for daily tech-team logging, built in Power Automate.

ROLE
Flow design and setup
FORMAT
Scheduled team reminder
TOOLS
Power Automate, Microsoft Teams, Adaptive Cards
STATUS
Built workflow

Why I built it

Daily work logging can slip when a reminder depends on one person sending it. I wanted the tech team to receive the same prompt on workdays in Microsoft Teams, where the team already communicates, and to make the reminder easy to inspect when delivery needs attention.

What I built

  • A Power Automate flow scheduled for 6:00 AM on weekdays.
  • An Adaptive Card reminder for daily tech-team work logging.
  • Delivery through Microsoft Teams.

Operating procedure

  1. Confirm the schedule and audience

    Check the weekday recurrence, 6:00 AM run time, Teams destination, and card wording before enabling the flow.

  2. Run a controlled test

    Trigger a test and verify that the Adaptive Card renders in the intended Teams space.

  3. Check delivery

    Review Power Automate run history for failures and confirm that the posted message is readable.

  4. Maintain the reminder

    Update the message or destination when the team process changes, then test again.

Outcome and limits

The built flow has a weekday trigger, an Adaptive Card, and a Teams delivery action. Those are the verified components shown in the process diagram. I have not measured time saved, logging compliance, or the effect on end-of-day reports, so this case study does not present a percentage improvement.

Current status: The scheduled reminder is built. A separate EOD collection workflow remains under development and is not part of this case study.

BUILT PROJECT / DESKTOP AUTOMATION

Session Segregator

A guided desktop tool that separates paired session trajectories and applies the right task descriptions without manual file-by-file edits.

ROLE
Workflow and GUI development
FORMAT
Python desktop utility
TOOLS
Python, Tkinter, file processing
STATUS
Built project; private session data excluded

The problem

Some recording tasks have two language instructions for the forward and reset actions. Operators had to record a task, reset it, and repeat the task for the second instruction. Descriptions also needed careful manual editing, which created an opportunity for inconsistent metadata.

What I built

  • A desktop flow that places even-numbered trajectories in the first instruction folder and odd-numbered trajectories in the second.
  • A task selector that suggests the two matching descriptions while keeping both editable for review.
  • A targeted update that changes descriptions while preserving the rest of each session file's structure.

Operating procedure

  1. Choose the completed session folder and inspect the task and trajectory sequence.
  2. Run the split; confirm the even and odd trajectories appear in the expected folders.
  3. Select the task, review both suggested instructions, and correct either description if needed.
  4. Apply the description update, then spot-check the output files before handoff.

How it helped

The paired actions can be captured in one recording sequence and sorted afterward. This removes repeated description editing and gives operators a review step before the files move downstream. The tool's design addresses a specific production bottleneck; a timed before-and-after study is not included here.

E-commerce order QA

A reproducible local audit of order lines and a separate SKU inventory export. It checks missing values in context and publishes aggregate results without exposing source records.

ORDER REPORT
128,975 order lines
INVENTORY LIST
9,271 rows
METHOD
Python CSV checks

Aggregate JSON only

The processing problem

The sales report is an order-line export. One Order ID can occur on several lines, so removing every repeated ID would discard valid items. The inventory file is a separate SKU list with no snapshot date, so it can show catalog coverage but cannot explain whether an order was fulfilled.

Missing amounts and zero quantities also need status context. In this sample, most occur on canceled lines. The useful review queue is the smaller set that remains after status is considered.

What I built

  • A standard-library Python script that streams both CSVs and checks required columns before analysis.
  • Status-aware counts for blank Amount and zero Qty, plus a count of rows missing a shipping field.
  • Separate checks for repeated Order IDs, repeated Order ID and SKU pairs, and rows identical after excluding the export index.
  • An exact, whitespace-trimmed SKU comparison between sales lines and the inventory list.
  • A JSON output with counts only. Identifiers, locations, customer details, and prices are never exported.

What the checks found

7,795lines have no amount; 7,566 are canceled, leaving 229 other lines for review.
12,807lines have zero quantity; 12,701 are canceled, leaving 106 other lines for review.
6,617 / 7,195distinct sales SKUs appear in the inventory list; 578 do not match its SKU codes.
33lines lack at least one shipping-location field; the values themselves stay private.

Another 8,597 lines share an Order ID with an earlier line. That is a grain check, not a duplicate count. Six rows are otherwise identical after excluding the generated index; those warrant review before any removal.

How to inspect it

The analysis runs locally against the two source CSVs and writes the aggregate summary shown here. The script and the resulting count file are available for review. Source CSVs are kept out of the portfolio.

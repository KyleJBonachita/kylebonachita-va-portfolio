BUILT PROJECT / APPS SCRIPT WEB APP

NVIDIA Session Hub

A central intake page for robotics session submissions, with structured inputs, validation, and routing to sheet-based trackers.

ROLE
Apps Script development
FORMAT
Internal web app
TOOLS
Google Apps Script, Google Sheets, JavaScript
STATUS
Built project; internal records excluded

The problem

Session details entered across separate trackers are hard to keep consistent. Missing fields, different task names, or a submission placed in the wrong sheet can slow verification and make the next handoff harder to trace.

What I built

  • A single intake flow with structured operator and session fields.
  • Task choices driven by metadata, with validation before a submission is accepted.
  • Writes that route a validated submission to the relevant sheet-based outputs.

Operating procedure

  1. Open the intake page and enter the required session details.
  2. Select the task from the available metadata-driven choices.
  3. Resolve validation messages before submitting.
  4. Confirm the submission in the destination tracker and follow the team's exception process if it is missing.

How it helped

The form guides operators through the same fields and checks each time. That standardizes the information passed to downstream trackers and makes a missing or invalid submission easier to identify. The case study does not include measured processing-time or error-rate results.

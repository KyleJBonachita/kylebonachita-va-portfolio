BUILT PROJECT / DESKTOP TOOL

Foot Pedal Configurator

A standalone Python interface for finding auxiliary input devices and turning their buttons into useful key, text, or macro actions.

ROLE
Desktop GUI development
FORMAT
Local utility
TOOLS
Python, Tkinter, input-device mapping
STATUS
Built project; device-specific setup required

The problem

Some pedals do not ship with a usable configuration app. Operators can end up installing different utilities and repeating manual mapping whenever a device or workstation changes.

What I built

  • A guided scan that compares connected input devices before and after a new pedal, keyboard, or mouse is inserted.
  • A mapping step for selected inputs to keys, strings, or macros, while leaving unconfigured inputs disabled.
  • A background footswitch mode with a small floating control so the mapping can stay available during work.

Operating procedure

  1. Scan the current input devices, connect the device to configure, and scan again to identify it.
  2. Select which input controls need a new action.
  3. Assign each action and review any control that should remain disabled.
  4. Run the background mode and test every mapped action in a safe test field before production use.

How it helped

The application puts detection and mapping into one guided interface. Operators can repeat a known setup flow instead of finding a separate configuration utility for each device. No measured setup-time reduction is claimed here.

Evidence and limits: The workflow is described in my earlier portfolio and first-person project notes. A physical pedal and local device permissions are required for the actual application, so this page shows the method rather than a browser-controlled hardware demo.
